# Forcefields Draft Dictionary

A list of data fields to describe forcefield-based methods. Main data fields are available in `cspcore.md` file.

| Group         | Data Field                 | Type       | Definition                                                                                  | Constraints | Units | Example                                                                                       |
|---------------|----------------------------|------------|---------------------------------------------------------------------------------------------|-------------|-------|-----------------------------------------------------------------------------------------------|
| `_forcefield` | `version`                  | char       | Version of the force field                                                                  | Free Text   |       |                                                                                               |
| `_forcefield` | `bond_type`                | char       | Functional form of the bond stretching potential                                            | Free Text   |       | "Harmonic"<br/>- "Morse"<br/>- "Cubic bond stretching potential"<br/>- "ReaxFF Bond Term"     |
| `_forcefield` | `angle_type`               | char       | Functional form of the angle bending potential                                              | Free Text   |       | "Harmonic"<br/>- "Cosine"<br/>- "Restricted bending"<br/>- "Linear"<br/>- "ReaxFF Angle Term" |
| `_forcefield` | `improper_type`            | char       | Functional form of the improper dihedral potential                                          | Free Text   |       | "Harmonic"                                                                                    |
| `_forcefield` | `dihedral_type`            | char       | Functional form of the dihedral torsional potential                                         | Free Text   |       | "Periodic"<br/>- "Ryckaert-Bellemans"<br/>- "Fourier"<br/>- "ReaxFF Torsion Term"             |
| `_forcefield` | `cross_terms`              | list[char] | Specifies the inclusion and functional form of cross terms (e.g., bond-angle, Urey-Bradley) | Free Text   |       |                                                                                               |
| `_forcefield` | `1-4_pairs`                | bool       | Indicates whether 1-4 interactions (Lennard-Jones and electrostatic) are scaled             |             |       | True                                                                                          |
| `_forcefield` | `fudgeLJ`                  | numb       | Scaling factor applied to 1-4 Lennard-Jones interactions                                    | 0.-1.       |       | 0.5                                                                                           |
| `_forcefield` | `fudgeQQ`                  | numb       | Scaling factor applied to 1-4 electrostatic interactions                                    | 0.-1.       |       | 0.5                                                                                           |
| `_forcefield` | `charges_generation`       | char       | Description of the method used to generate atomic partial charges                           | Free Text   |       | "BCC-AM1"<br/>- "Mulliken-AM1"                                                                |
| `_forcefield` | `multipoles_generation`    | char       | Description of the method used to generate atomic multipoles                                | Free Text   |       | DMA                                                                                           |
| `_forcefield` | `multipole_max_rank`       | char       | The rank of the multipoles                                                                  | Free Text   |       | Hexadecapole                                                                                  |
| `_forcefield` | `long_range_electrostatic` | char       | Method used to treat long-range electrostatic interactions                                  | Free Text   |       | "Ewald"<br/>- "PME"                                                                           |
| `_forcefield` | `polarisation`             | char       | Method used to model electronic polarisation                                                | Free Text   |       | "Thole"<br/>- "Anharmonic"                                                                    |
| `_forcefield` | `hb_correction`            | char       | Hydrogen bond correction term.                                                              | Free Text   |       |                                                                                               |
| `_forcefield` | `lone_pair_correction`     | char       | Lone pair correction term.                                                                  | Free Text   |       |                                                                                               |
| `_forcefield` | `long_range_vdw`           | char       | Method used to treat long-range van der Waals interactions                                  | Free Text   |       | "Energy"<br/>- "Pressure"<br/>- "EnergyPressure"<br/>- "LJ PME"                               |
| `_forcefield` | `combination_rule`         | char       | Rule used to calculate Lennard-Jones cross-interaction parameters                           | Free Text   |       | "Geometric"<br/>- "Arithmetic"<br/>- "Lorentz-Berthelot"                                      |
